# Student Task Manager App

A simple student task manager built with React and Tailwind CSS using Bolt.new.

## Features
- Add, edit and delete tasks
- Mark tasks as complete
- Filter tasks: All, Pending, Completed
- Sidebar layout with a blue and white theme
- Tasks saved in local storage

## Live Demo
https://student-task-manager-tjml.bolt.host

## Installation
1. git clone https://github.com/PIYUSHRAJ-ctrl1515/student-task-manager-app.git
2. cd student-task-manager-app
3. npm install
4. npm run dev
5. Open http://localhost:5173
